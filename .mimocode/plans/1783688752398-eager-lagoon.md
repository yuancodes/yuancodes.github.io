# 修改计划：gensidebar.js 支持按 order 属性排序文章

## 问题分析

当前 `docs/gensidebar.js` 脚本在读取 front matter 中的 `order` 属性时，正则表达式 `^---\n([\s\S]*?)\n---` 只能匹配 `\n`（Unix 换行符），无法匹配 `\r\n`（Windows 换行符）。

由于不同文件的换行符不一致（有些是 `\n`，有些是 `\r\n`），导致大部分文件的 `order` 值读取失败（返回 `Infinity`），文章按文件名字母顺序排序而非按 `order` 排序。

## 修改方案

### 修改文件

`docs/gensidebar.js` - 第 10 行

### 具体修改

将第 10 行的正则表达式：
```javascript
var match = content.match(/^---\n([\s\S]*?)\n---/);
```

修改为：
```javascript
var match = content.match(/^---\r?\n([\s\S]*?)\r?\n---/);
```

### 修改说明

- `\r?` 表示可选的 `\r` 字符
- 这样正则表达式可以同时匹配 `\n` 和 `\r\n` 两种换行符格式
- 其他逻辑无需修改

## 验证方法

1. 修改后运行 `node gensidebar.js`
2. 检查生成的 `_sidebar.md` 文件
3. 确认文章按 `order` 属性从小到大排序
