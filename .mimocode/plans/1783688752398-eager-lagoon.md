# 博客搜索优化 - 预生成索引方案

## 已完成

### 1. 创建搜索索引生成脚本
**文件**：`docs/build-search-index.js`
- 扫描 `docs/` 目录下所有 `.md` 文件（671 个）
- 提取文件标题（从 front matter 或文件名）
- 提取文件内容（去除 front matter，去除代码块、HTML 标签等）
- 生成 `search-index.json`（330 KB）

### 2. 创建搜索插件
**文件**：`docs/js/search-index.min.js`
- 加载 `search-index.json`（单次请求）
- 实现客户端搜索（支持中文）
- 支持标题匹配和内容匹配
- 显示搜索结果摘要和高亮关键词

### 3. 修改 index.html
- 禁用原有 `search.min.js` 插件
- 添加新的 `search-index.min.js` 插件
- 注释掉原有的 search 配置

### 4. 修改 gensidebar.js
- 在生成侧边栏的同时调用索引生成脚本
- 修复备份文件的错误处理

---

## 使用方法

### 日常更新流程
```bash
# 1. 在 docs/ 目录下执行（新增/删除文章后）
cd docs
node gensidebar.js

# 脚本会自动：
# - 生成 _sidebar.md（侧边栏）
# - 生成 search-index.json（搜索索引）
```

### 本地测试
```bash
# 在仓库根目录执行
docsify serve docs
# 访问 http://localhost:3000
```

## 性能对比

| 指标 | 优化前 | 优化后 |
|------|--------|--------|
| 首次搜索请求 | 671 个 HTTP 请求 | 1 个请求（330KB） |
| 搜索速度 | 慢（需加载所有文件） | 快（内存中搜索） |
| 搜索准确性 | 简单字符串匹配 | 标题+内容匹配，支持高亮 |
