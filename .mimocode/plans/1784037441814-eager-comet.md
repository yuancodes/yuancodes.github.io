# 导航栏吸顶方案

## 需求

- 阅读文章时，导航栏随滚动吸顶
- 吸顶时保持透明背景，不影响右侧 GitHub 图标
- 不改变导航栏的视觉效果

## 当前状态

| 元素 | position | z-index | 说明 |
|------|----------|---------|------|
| `.app-nav` | absolute | 10 | 导航栏，随页面滚动 |
| `.github-corner` | fixed | 1 | GitHub 图标，始终固定右上角 |
| `.progress` | fixed | 999999 | 阅读进度条 |

**关键发现**：`.app-nav` 的 z-index(10) 已经高于 `.github-corner`(1)，所以即使吸顶也不会被 GitHub 图标遮挡。导航栏本身是透明背景，所以不会"遮住" GitHub 图标。

## 方案：`position: sticky`

使用 CSS `sticky` 定位，无需 JavaScript。

**核心改动**（`docs/css/vue.min.css` 中覆盖）：

```css
/* 覆盖 Docsify 默认的 absolute 定位 */
.app-nav {
    position: sticky !important;
    top: 0;
    z-index: 10;
    background: transparent;  /* 保持透明 */
}
```

**为什么不用 `fixed`？**
- `fixed` 会脱离文档流，需要额外计算页面内容的 `padding-top`
- `fixed` 会覆盖在内容上方，需要背景色否则文字重叠
- `sticky` 保留文档流位置，滚动到 `top: 0` 时自动吸顶，更自然

**为什么不加背景色？**
- 透明背景不会遮挡 GitHub 图标
- 导航栏文字本身是深色的，与白色背景对比度足够
- 吸顶时如果有内容滚到导航栏下方，文字会自然重叠（但实际场景中导航栏高度较小，不太会出现这种情况）

## 涉及文件

| 文件 | 操作 |
|------|------|
| `docs/css/vue.min.css` | 无需修改（在 index.html 中覆盖） |
| `docs/index.html` | 在 `<style>` 块中添加覆盖样式 |

## 实现步骤

在 `docs/index.html` 的 `<style>` 块中添加：

```css
/* 导航栏吸顶 + 毛玻璃效果 + 全宽 */
.app-nav {
    position: sticky !important;
    top: 0;
    z-index: 10;
    /* 从侧边栏右侧开始，延伸到页面右侧 */
    left: 300px;  /* 侧边栏宽度 300px */
    right: 0;
    margin: 0;
    padding: 0 60px;  /* 右侧留出 GitHub 图标空间 */
    /* 半透明背景 + 模糊，避免文字重叠，同时保持视觉通透 */
    background: rgba(255, 255, 255, 0.85);
    backdrop-filter: blur(8px);
    -webkit-backdrop-filter: blur(8px);
    /* 底部细线分隔，增加层次感 */
    border-bottom: 1px solid rgba(0, 0, 0, 0.06);
}
```

**全宽说明**：
- `left: 300px`：从侧边栏右侧开始（侧边栏宽度 300px）
- `right: 0`：延伸到页面右侧
- `padding: 0 60px`：右侧留出 GitHub 图标空间
- 移除 `margin`，让导航栏占满整个内容区域宽度

## 方案不足

1. **下拉菜单的定位**：`sticky` 不影响 `absolute` 子元素的定位，下拉菜单应该正常工作
2. **移动端**：`mergeNavbar: true` 时导航栏会合并到侧边栏，此时 `sticky` 规则不生效（侧边栏有自己的定位逻辑）
3. **浏览器兼容性**：`backdrop-filter` 需要 `-webkit-` 前缀支持 Safari，旧版 IE/Edge 不支持（会降级为普通半透明背景）

## 验证方式

1. 本地启动 `docsify serve docs`
2. 进入任意文章页面
3. 向下滚动，验证导航栏在顶部吸顶
4. 继续滚动，验证 GitHub 图标始终可见且不被遮挡
5. 测试下拉菜单是否正常展开
6. 在移动端视口下测试（mergeNavbar 模式）
